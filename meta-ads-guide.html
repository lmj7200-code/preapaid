화면이 다르게 보일 때

메타는 메뉴 이름과 위치를 자주 바꿉니다. 이 문서와 화면이 조금 다르면 비슷한 이름을 찾거나, 광고 관리자 오른쪽 위 검색창에 기능 이름을 입력하세요. 설정의 의미와 순서는 거의 바뀌지 않습니다.

절대 하지 말 것
  • 다른 사람의 페이스북 아이디·비밀번호를 받아서 로그인하지 마세요. 해킹 의심으로 계정이 잠기고 광고 계정까지 정지될 수 있습니다. 본인 계정으로 로그인한 뒤 권한을 받아서 작업합니다(부록 A).
  • 광고 계정이 정지됐을 때 새 계정을 만들어 우회하지 마세요. 비즈니스 전체가 정지될 수 있습니다.
스크린샷 넣는 법

문서 곳곳의 빗금 상자가 스크린샷 자리입니다. 상자에 적힌 파일명 그대로 이미지를 저장해 이 HTML 파일 옆의 meta-guide-img 폴더에 넣으면 자동으로 사진이 표시됩니다. 캡처할 때 광고 계정 ID, 카드 번호, 고객 정보는 가려 주세요.

01

이름 설정 규칙 (레딜 방식)

이름만 보고도 누가, 언제, 무엇을, 누구에게 광고하는지 알 수 있어야 합니다. 성과표에서 필터로 찾고, 다른 사람이 인수받을 때 헷갈리지 않게 하기 위해서입니다. 레딜은 아래 규칙으로 통일합니다.

공통 규칙
  • ★ 단어 사이는 띄어쓰기 대신 밑줄(_)로 구분합니다.
  • ★ 날짜는 6자리 YYMMDD(예: 2026년 10월 7일 → 261007). 캠페인을 처음 켠 날 기준입니다.
  • ★ 항목 순서를 바꾸지 않습니다. 해당 없는 칸은 비우지 말고 전체 또는 NA로 씁니다.
  • 특수문자(/ \ # & ? %)는 쓰지 않습니다. UTM으로 넘어갈 때 URL이 깨집니다.
  • 복제한 뒤 이름 끝에 붙는 “- 사본”은 반드시 지우고 규칙대로 고칩니다.

구매 유형 새 캠페인 창 맨 위

경매와 예약(도달 및 빈도) 중 고릅니다. 경매는 실시간 입찰로 광고비가 정해지고, 예약은 미리 정한 가격으로 노출을 사는 방식입니다(대형 브랜드 광고용).

레딜 기준

항상 경매.

★ 캠페인 목표 새 캠페인 창

메타가 “어떤 사람을 찾아 줄지”를 정하는 가장 중요한 설정입니다. 캠페인을 만든 뒤에는 바꿀 수 없으므로 잘못 고르면 새로 만들어야 합니다.

레딜 기준

광고주가 원하는 최종 결과와 맞춥니다. 신청·상담 DB가 목적이면 잠재 고객, 결제가 목적이면 판매. “일단 클릭이라도 많이”라는 이유로 트래픽을 고르지 않습니다.

캠페인 설정 방식 목표 선택 후 · Advantage+ 스위치

Advantage+ 캠페인을 켜면 예산 배분, 타겟, 노출 위치를 메타가 자동으로 정합니다. 끄면(수동) 각 항목을 직접 설정합니다. 수동으로 만들어도 각 항목에서 Advantage+를 개별로 켤 수 있습니다.

레딜 기준

처음 배울 때는 수동으로 만들어 각 항목을 직접 확인합니다. 화면에 Advantage+ 캠페인 표시가 켜져 있으면 무엇이 자동인지 확인한 뒤 진행합니다.

★ 캠페인 이름 캠페인 설정 맨 위

기본으로 “새 잠재 고객 캠페인” 같은 이름이 들어가 있습니다. 반드시 지우고 다시 씁니다.

신용·금융 상품, 고용(채용), 주택, 사회 문제·선거·정치 광고는 반드시 선택해야 합니다. 선택하면 나이·성별·상세 타겟 사용이 제한되고, 선택하지 않고 해당 광고를 내면 반려·계정 제한을 받습니다.

A/B 테스트 스위치

켜면 두 가지 버전(소재, 타겟, 노출 위치 등)을 사람이 겹치지 않게 나눠 공정하게 비교합니다. 한 번에 한 가지 조건만 다르게 해야 결과를 해석할 수 있습니다.

레딜 기준

기본은 끔. 소재나 타겟 비교 테스트를 기획했을 때만 켜고, 이름 구분 칸에 테스트를 씁니다.

★ 예산 (Advantage+ 캠페인 예산 / 광고 세트 예산) 예산 영역

캠페인 예산을 고르면 캠페인 전체 예산을 정하고 메타가 광고 세트 사이에 알아서 나눕니다. 광고 세트 예산을 고르면 광고 세트마다 예산을 따로 정합니다.

  • 일일 예산: 하루 평균 쓸 금액. 하루에 최대 약 75% 더 쓸 수 있지만 일주일 평균은 맞춰집니다.
  • 총예산: 기간 전체에 쓸 금액. 종료일이 꼭 필요합니다.
레딜 기준

광고 세트가 2개 이상인 상시 캠페인은 캠페인 예산 + 일일 예산. 타겟끼리 성과를 정확히 비교하는 테스트일 때만 광고 세트 예산. 입력 전 광고주와 합의한 월 예산 ÷ 30을 넘지 않는지 계산합니다. 0을 하나 더 붙이는 실수를 막으려고, 입력 후 금액을 소리 내어 한 번 읽습니다.

★ 광고 세트 이름

레딜 기준

  • 즉석 양식: 페이스북·인스타 안에서 바로 이름·연락처 입력. 신청 수는 많고 질은 낮은 편.
  • 메시지 앱: 메신저·인스타 DM·왓츠앱 상담.
  • 통화: 광고에서 바로 전화 걸기.
  • 웹사이트 및 즉석 양식 등 여러 위치를 함께 고르는 옵션도 있습니다.
레딜 기준

광고주와 정한 DB 수집 방식에 맞춥니다. 랜딩페이지가 있으면 기본은 웹사이트. 즉석 양식이면 양식 질문과 개인정보 처리방침 링크를 광고주에게 확인받습니다.

★ 성과 목표 전환 영역

메타가 무엇을 최대화할지 정합니다. 잠재 고객 목표라면 전환수 최대화(웹사이트), 잠재 고객 수 최대화(즉석 양식), 전환 잠재 고객 수 최대화(CRM 연동 시) 등이 나옵니다.

레딜 기준

웹사이트 전환이면 전환수 최대화. “랜딩페이지 조회수 최대화”나 “링크 클릭수 최대화”를 고르면 신청하지 않는 사람에게 광고가 나가므로 고르지 않습니다.

★ 데이터세트(픽셀) · 전환 이벤트 전환 영역

어떤 픽셀의 어떤 이벤트를 “전환”으로 볼지 고릅니다. 이벤트 옆에 초록 점이 있으면 최근에 데이터가 들어오고 있다는 뜻입니다.

레딜 기준

① 이 광고주의 픽셀이 맞는지(다른 클라이언트 픽셀을 고르는 실수 주의), ② 이벤트가 신청 완료(Lead) 또는 결제 완료(Purchase)인지, ③ 이벤트에 초록 점(활성)이 있는지 세 가지를 확인합니다. 회색이면 픽셀부터 점검합니다(부록 A).

다이나믹 크리에이티브 전환 영역 아래 스위치

켜면 이미지·문구·제목을 여러 개 넣고 메타가 조합을 바꿔 가며 보여 줍니다. 켜면 광고 하나에 소재를 묶어서 넣게 됩니다.

레딜 기준

기본은 끔. 소재별 성과를 이름으로 구분해 보기 위해 광고를 하나씩 따로 만듭니다.

비용 관리 광고 세트 예산일 때 표시 · 선택 사항

전환 1건에 목표로 하는 비용(또는 상한)을 입력합니다. 너무 낮으면 광고가 거의 나가지 않습니다.

레딜 기준

처음에는 비워 둡니다.

★ 예산 및 일정 예산 및 일정 영역

  • 예산: 캠페인 예산을 껐을 때만 여기에 입력합니다.
  • 시작 날짜: 기본값은 지금. 미래로 지정하면 그때 시작합니다.
  • 종료 날짜: 상시 광고는 비워 두고, 이벤트 광고는 꼭 지정합니다.
  • 광고 일정(총예산일 때): 요일·시간대를 지정해 그 시간에만 노출합니다.
레딜 기준

이벤트 광고는 종료 날짜를 반드시 입력합니다. 이벤트가 끝났는데 광고가 계속 나가면 광고비 낭비와 광고주 클레임이 생깁니다. 상담 인력이 있는 시간에만 받아야 하는 광고주는 광고 일정을 씁니다.

예산 정하는 기준: 광고 세트 하나가 일주일에 전환 약 50건을 얻어야 학습이 끝납니다. 하루 예산 ≈ 목표 CPA × 50 ÷ 7 (예: CPA 10,000원 → 하루 약 70,000원). 예산이 적으면 광고 세트 수를 줄여 몰아줍니다.

★ 타겟 타겟 영역

기본은 Advantage+ 타겟입니다. 메타가 전환할 사람을 알아서 찾고, 직접 넣은 나이·관심사는 “제안”으로만 씁니다. “기존 타겟 옵션 사용”을 누르면 조건을 고정하는 예전 방식으로 바뀝니다.

항목설명레딜 기준
지역국가·시·구·반경. “이 지역에 사는 사람” 또는 “최근 있었던 사람” 선택광고주 서비스 가능 지역만. 오프라인 매장형은 매장 반경

노출 위치 노출 위치 영역

Advantage+ 노출 위치를 그대로 두면 페이스북·인스타그램 피드, 스토리, 릴스, 메신저, Audience Network 중 성과가 좋은 곳에 메타가 배분합니다. 수동 노출 위치를 고르면 지면을 직접 빼거나 넣을 수 있습니다.

레딜 기준

기본은 Advantage+ 노출 위치. 광고주가 “인스타그램에만” 같이 요청했거나, Audience Network에서 무효 클릭이 많을 때만 수동으로 바꾸고 이름 노출위치 칸에 적습니다.

기여 설정 전환 영역 · 더 보기

광고를 보거나 클릭한 뒤 며칠 안에 전환하면 광고 성과로 셀지 정합니다. 기본값은 클릭 후 7일, 조회 후 1일입니다.

레딜 기준

기본값 유지. 광고주 보고서끼리 비교하려면 모든 캠페인이 같은 기준이어야 합니다.

레딜 기준

기본값(보통 수준 인벤토리) 유지.

광고 설정

광고는 실제로 사람들이 보는 화면입니다. 광고 하나에 소재 하나를 넣고, 한 광고 세트에 광고 3~6개를 만들어 메타가 잘 되는 소재를 고르게 합니다.

★ 광고 이름

레딜 기준

01장 규칙: 소재형식_소재번호_핵심메시지_버전. 소재번호는 원본 폴더 파일 번호와 같게.

파트너십 광고 스위치

인플루언서·크리에이터 계정 이름으로 광고를 내보낼 때 씁니다. 상대 계정의 승인이 필요합니다.

레딜 기준

인플루언서 협업 캠페인이 아니면 끔.

★ 아이덴티티 페이스북 페이지 · 인스타그램 계정 · 스레드

광고에 “누가 광고하는지”로 표시될 계정입니다. 인스타그램 계정을 고르지 않으면 페이스북 페이지 이름으로 인스타그램에 노출됩니다.

레딜 기준

이 광고주의 페이지와 인스타그램이 맞는지 확인합니다. 다른 클라이언트 페이지로 광고가 나가는 사고가 실제로 가장 치명적입니다.

광고 설정 방식 광고 만들기 / 기존 게시물 사용 / 크리에이티브 허브 모형

  • 광고 만들기: 이미지·영상을 새로 올려서 만듦. 기본.
  • 기존 게시물 사용: 페이지·인스타에 이미 올린 게시물을 광고로. 좋아요·댓글이 그대로 이어집니다.
  • 크리에이티브 허브 모형: 미리 만들어 둔 시안을 불러옴.
레딜 기준

기본은 광고 만들기. 오가닉 반응이 좋은 게시물을 키울 때만 기존 게시물 사용.

형식 광고 설정 영역

  • 단일 이미지 또는 동영상: 가장 기본.
  • 슬라이드(캐러셀): 카드 2~10장을 옆으로 넘김. 상품·요금제 여러 개 비교.
  • 컬렉션: 상품 카탈로그가 있는 쇼핑몰용.
레딜 기준

형식과 광고 이름의 소재형식(IMG·VID·CAR)이 일치하는지 확인.

다중 광고주 광고 형식 아래 체크박스

체크되어 있으면 다른 회사 광고와 한 묶음으로 노출될 수 있습니다.

레딜 기준

경쟁사와 함께 보이는 것을 원치 않는 광고주는 체크 해제. 광고주 방침을 따릅니다.

★ 미디어 (이미지·동영상) 광고 크리에이티브 › 미디어 추가

이미지나 영상을 올리면 노출 위치별 비율로 자동 잘림을 보여 줍니다. 위치별로 다른 파일을 지정할 수 있습니다.

★ 기본 문구 · 제목 · 설명 광고 크리에이티브

칸위치권장 길이예시

레딜 기준

문구는 광고주 승인본을 그대로 복사해 붙입니다(직접 타이핑하면 오타·가격 실수). 가격·혜택·기간이 랜딩페이지와 같은지, 부록 C의 금지 표현이 없는지 확인합니다.

★ 클릭 유도 버튼(CTA) 광고 크리에이티브

광고 아래 버튼 문구입니다. 신청하기, 문의하기, 자세히 알아보기, 구매하기, 지금 예약하기 등에서 고릅니다.

레딜 기준

캠페인 목표와 맞춥니다. 잠재 고객 → 신청하기·문의하기, 판매 → 구매하기. 랜딩페이지의 실제 버튼 문구와 비슷하게.

★ 도착 페이지 (웹사이트 URL) 목적지 영역

광고를 누르면 이동할 주소입니다. 즉석 양식이면 여기서 양식을 고르고, 메시지면 메시지 앱을 고릅니다.

  • 웹사이트 URL: 실제 랜딩 주소. https://부터 전체 주소를 넣습니다.
  • 표시 링크: 광고에 보이는 주소(선택). 도메인만 짧게 보여 줄 때.
  • URL 매개변수: UTM을 넣는 칸(05장).
레딜 기준

05장 방법대로 넣고, [URL 미리보기]를 눌러 실제로 열리는지 반드시 확인합니다. 광고 URL 칸에는 단축 URL을 넣지 않습니다.

Advantage+ 크리에이티브 미디어·문구 아래 · 크리에이티브 개선 사항

메타가 소재를 자동으로 보정·변형합니다. 항목별로 켜고 끌 수 있습니다: 텍스트 개선(문구 위치 바꾸기), 이미지 확장, 밝기·대비 조정, 음악 추가, 이미지 애니메이션, 관련 링크·사이트 링크 추가 등.

레딜 기준

광고주가 소재 변형을 허용하지 않거나 가격·법적 고지 문구가 있는 소재는 텍스트 개선·이미지 확장·애니메이션을 끕니다. 그 외에는 켜 두되 미리보기로 이상한 결과가 없는지 봅니다.

언어 광고 크리에이티브 · 선택 사항

여러 언어 버전을 넣으면 보는 사람 언어에 맞춰 보여 줍니다. 국내 광고는 보통 쓰지 않습니다.

★ 추적 광고 화면 맨 아래

웹사이트 이벤트에 픽셀이 체크되어 있어야 전환이 기록됩니다. 앱 이벤트, 오프라인 이벤트는 해당될 때만 체크합니다.

레딜 기준

체크된 픽셀이 이 광고주의 픽셀인지 확인합니다.

★ 미리보기 → 게시

오른쪽 미리보기에서 피드, 스토리, 릴스, 검색 결과 등 위치를 하나씩 눌러 봅니다. “고급 미리보기”로 휴대폰에 미리보기를 보낼 수도 있습니다.

레딜 기준

06장 체크리스트를 다 확인한 뒤 [게시]. 게시 후 다음 날 오전에 게재 상태와 지출을 반드시 확인합니다.

기본 랜딩 URL → 웹사이트 URL 칸 물음표: 메타가 자동으로 붙임 UTM 매개변수 → URL 매개변수 칸

UTM은 GA4 같은 분석 도구에서 “어느 광고로 들어온 방문자인지” 구분하는 꼬리표입니다. 중괄호 {{...}}는 메타가 광고가 나갈 때 실제 캠페인·광고 세트·광고 이름으로 바꿔 줍니다. 그래서 01장의 이름 규칙이 분석 보고서에도 그대로 나타납니다.

매개변수레딜 값의미
utm_sourcemeta어디서 왔나 (고정)
utm_mediumpaid_social어떤 방식 (고정)
utm_campaign{{campaign.name}}캠페인 이름 자동 입력
utm_content{{ad.name}}광고 이름 자동 입력
utm_term{{adset.name}}광고 세트 이름 자동 입력

광고에 URL 넣는 방법

  1. 웹사이트 URL 칸에 기본 랜딩 URL만 붙여 넣기

    ? 뒤의 내용은 넣지 않습니다. 주소창에서 복사했다면 뒤에 붙은 ?fbclid=, ?utm_ 등을 지웁니다.

  2. URL 매개변수 칸에 레딜 UTM 붙여 넣기 
    utm_source=meta&utm_medium=paid_social&utm_campaign={{campaign.name}}&utm_content={{ad.name}}&utm_term={{adset.name}}

    칸 옆의 “URL 매개변수 만들기”를 누르면 항목을 하나씩 고르는 화면이 나옵니다. 직접 붙여 넣는 것이 더 빠르고 실수가 적습니다.

  3. [URL 미리보기] 클릭

    새 창에서 랜딩페이지가 열리고, 주소창 끝에 utm_source=meta…가 붙어 있으면 성공입니다. 페이지가 안 열리거나 다른 페이지로 넘어가면 URL을 다시 확인합니다.

  4. 여러 광고에 같은 URL을 넣을 때

    광고 하나를 완성한 뒤 복제하면 URL과 매개변수가 그대로 복사됩니다. 소재와 이름만 바꾸면 됩니다.

URL 단축 방법

광고 URL 칸에는 단축 URL 금지

메타 광고의 웹사이트 URL에 단축 URL을 넣으면 리디렉션 때문에 검토에서 반려되거나, 픽셀·UTM 추적이 끊길 수 있습니다. 광고에는 항상 원래 주소를 넣습니다.

단축 URL은 광고 밖에서 씁니다: 인스타그램 프로필 링크, 게시물 댓글, 카카오톡·문자 발송, 광고주 보고용 공유 등. 이때도 UTM을 붙인 긴 주소를 단축해야 어디서 들어왔는지 구분됩니다.

  1. 단축할 긴 주소 만들기

    광고 밖에서 쓰는 링크는 {{...}} 자동 값이 작동하지 않으므로 직접 값을 씁니다.

    https://도메인/index.html?utm_source=instagram&utm_medium=profile&utm_campaign=261007_마크통신_상시
  2. 단축 도구 접속

    레딜 지정 도구: [레딜 기입: 예) Bitly 팀 계정]. 개인 계정으로 만든 단축 링크는 퇴사 시 관리가 끊기므로 팀 공용 계정으로 로그인합니다.

  3. Bitly 기준: [Create new] → [Link] → 긴 주소 붙여 넣기

    “Destination” 칸에 1번 주소를 넣습니다. “Title”에는 캠페인 이름을 써서 나중에 찾기 쉽게 합니다.

  4. 뒷부분 직접 지정(선택)

    “Back-half”에 mark-1007처럼 알아보기 쉬운 단어를 넣으면 bit.ly/mark-1007 형태가 됩니다.

  5. [Create] → 복사 → 직접 열어 확인

    단축 주소를 휴대폰과 PC에서 열어 올바른 랜딩으로 가는지 확인하고, 단축 URL과 원래 주소를 부록 D 표에 기록합니다.

계정·픽셀 준비

새 광고주를 처음 세팅하거나, 인수인계로 권한을 받을 때 한 번만 하는 작업입니다.

권한 받기

  1. 본인 페이스북 계정 2단계 인증 켜기

    설정›계정 센터›비밀번호 및 보안›2단계 인증

  2. 기존 관리자가 비즈니스 포트폴리오에 초대

    비즈니스 설정›사용자›사람›추가에서 내 이메일 입력, 전체 관리 권한.

  3. 초대 메일 수락 후 자산 권한 확인

    내 이름을 눌러 페이지, 인스타그램, 광고 계정, 데이터세트(픽셀) 모두에 권한이 있는지 봅니다. 하나라도 빠지면 광고를 만들 때 목록에 안 보입니다.

  4. 전임자 권한 정리

    관리자가 최소 2명 이상 남아 있는지 확인한 뒤 퇴사자 권한을 삭제합니다.

새 광고 계정·결제

  1. 광고 계정 만들기

    비즈니스 설정›계정›광고 계정›추가. 시간대 Asia/Seoul, 통화 KRW. 둘 다 나중에 바꿀 수 없습니다.

  2. 결제 수단 등록 · 계정 지출 한도 설정

    광고 관리자›결제 및 청구. 카드 한도가 부족해 결제가 실패하면 광고가 즉시 멈춥니다. 지출 한도를 걸어 두면 실수로 큰 예산을 넣어도 그 이상 쓰이지 않습니다.

  3. 페이지·인스타그램 연결

    비즈니스 설정›계정›페이지 / Instagram 계정. 인스타그램은 프로페셔널 계정이어야 합니다.

픽셀 설치

  1. 데이터세트(픽셀) 만들기

    이벤트 관리자›데이터 소스 연결›웹. 사이트당 1개. 이미 있으면 새로 만들지 않습니다.

  2. 모든 페이지 <head>에 기본 코드 설치 
    <!-- Meta Pixel Code -->
<script>
!function(f,b,e,v,n,t,s){...메타가 준 코드 그대로...}
fbq('init', '픽셀ID숫자');
fbq('track', 'PageView');
</script>
<!-- End Meta Pixel Code -->
  3. 전환 이벤트 코드 추가

    신청이 완료된 화면에서 발생해야 합니다. 버튼 클릭에 걸면 중간에 그만둔 사람까지 잡혀 숫자가 부풀려집니다.

    fbq('track', 'Lead');      // 상담·개통 신청 완료
fbq('track', 'Contact');   // 전화·카카오톡 상담 버튼
fbq('track', 'Purchase', {value: 30000, currency: 'KRW'}); // 결제 완료
  4. 설치 확인

    크롬 확장 프로그램 Meta Pixel Helper 또는 이벤트 관리자›이벤트 테스트에서 직접 신청해 보고 이벤트가 잡히는지 확인합니다.

  5. 도메인 인증

    비즈니스 설정›브랜드 가치 보호›도메인에서 메타 태그를 <head>에 넣거나 DNS TXT 레코드로 인증합니다.
